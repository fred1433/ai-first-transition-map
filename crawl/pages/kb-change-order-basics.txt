How to Create a Change Order

Purpose

To create a Change Order in Contractor Foreman.

Background

In Contractor Foreman, Change Orders are used to document and track any modifications made to the original contract amount.
They help you monitor who requested and approved the change, contractors involved, schedule delays, and any related photos or files.

Points to Remember

Required fields are marked with an asterisk (*).

To save your work, click the blue “Save” button at the bottom of the page.

To edit a record, click the green pencil icon in the upper right corner.

Only users with Admin Rights or those granted specific permissions can delete Change Orders.

To delete a Change Order:

Click the Action Items (three-dot icon) in the upper-right corner, or

Click the Action dropdown menu at the bottom right of the screen.

Steps to Create a New Change Order

Navigate to the Main Menu.

Click on the Change Orders module (under Financials).

Click the blue “+” icon on the left-hand side.

Enter the following information:

No Cost Change Order
Check this box if the Change Order will not affect the total contract amount.

Save Change Order as Template
Check this box to save the Change Order as a reusable template.

1. Import from Cost Items Database

Use the Cost Items Database (CIDB) to add existing cost items to the Change Order. The database can include materials, labor, equipment, subcontractor, and other costs, along with their associated pricing.

Select the items you want to include in the Change Order, then add them to the Change Order.

2. Import from Estimate

Import items directly from the Original Estimate for the project.
A pop-up window will display the estimate items. Select the items you wish to include.

3. Import from Change Order Requests

Import items from existing Change Order Requests (CORs) already entered in the system.
Select the COR from the dropdown and check the desired items.

4. Import from Change Order Template

Use a previously saved Change Order Template.
Select the template from the dropdown and choose which items to include.

5. Add Manual Change Order Item

To manually create a new line item, select Add Manual Change Order Item.
A pop-up window will appear. Complete the required fields.

Change Order Status

Each Change Order status represents a different stage in the process and may trigger automations that affect other modules in Contractor Foreman.

Status
Description

On Hold / Open
The Change Order can still be revised. The total amount is not yet included in the project total.

Pending Approval
Automatically assigned when the Change Order is sent to the customer for review.

Unbilled / Approved
Once approved by the customer, the Change Order becomes part of the Total Project Amount, Schedule of Values, and Job Cost Report.

Billed
Applied when the Change Order amount has been fully invoiced to the client.

To Submit for Approval:

Click the three-dot icon.

Select View/Email PDF.

Choose a template.

Click Submit for Approval.

Additional Tips

Review all details before sending a Change Order for approval.

Use templates and the CIDB to save time when creating future Change Orders.

Use internal notes to document reasoning or clarifications.
